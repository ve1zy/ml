## ВВЕДЕНИЕ

### Актуальность темы

Современные системы машинного обучения требуют не только точных моделей, но и удобных инструментов для их демонстрации и использования конечными пользователями. Инференс ML-моделей — ключевой этап жизненного цикла ML, позволяющий получать практические результаты на реальных данных. Streamlit [3] — это современная Python-библиотека, позволяющая быстро создавать веб-приложения без знания веб-технологий.

### Стек технологий

В работе применялись: **scikit-learn** [1] — для классических моделей (логистическая/ридж-регрессия, бэггинг, стэкинг), **XGBoost** [4] и **CatBoost** [5] — для градиентного бустинга, **TensorFlow/Keras** [2] — для построения глубоких нейронных сетей, **Pandas/NumPy** — обработка данных, **Matplotlib/Seaborn** — визуализация, **Streamlit** — фулстек-фреймворк для UI.

### Цель и задачи РГР

**Цель:** разработать веб-приложение (дашборд) для инференса моделей ML и визуализации данных.

**Задачи:**
1. Сформировать и предобработать наборы данных `cars` (регрессия) и `diabetes` (классификация), обучить и сериализовать 6 лучших моделей для каждой задачи.
2. Разработать многостраничный дашборд на Streamlit с описательными, визуализационными и инференсомодульными компонентами.
3. Провести демонстрацию прогнозирования на корректных и аномальных данных, зафиксировать результаты.

## 1. ОПИСАНИЕ ВЫБРАННЫХ МОДЕЛЕЙ И ИХ СЕРИАЛИЗАЦИЯ

### 1.1 Описание моделей

Для каждой задачи отобрано 6 моделей по критериям R² (регрессия) и F1 weighted (классификация):

**Регрессия (цена авто):**
- **ML1 — Ridge Regression** — линейная регрессия с L2-регуляризацией (scikit-learn).
- **ML2 — XGBoost** — градиентный бустинг решающих деревьев с регуляризацией и ранней остановкой.
- **ML3 — CatBoost** — бустинг с нативной обработкой категориальных признаков и упорядоченным бустингом.
- **ML4 — Bagging** — ансамбль DecisionTreeRegressor с бутстрап-агрегированием (scikit-learn).
- **ML5 — Stacking** — мета-ансамбль из Ridge + SVR + DecisionTree, финальный Ridge (scikit-learn).
- **ML6 — Neural Network** — полносвязная сеть [128→Dropout(0.2)→64→Dropout(0.2)→32→1] (TensorFlow/Keras).

**Классификация (диагностика диабета):**
- **ML1 — Logistic Regression** — многоклассовая логистическая регрессия (solver=lbfgs).
- **ML2 — XGBoost** — бустинг с objective=multi:softmax.
- **ML3 — CatBoost** — многоклассовая классификация (loss_function=MultiClass).
- **ML4 — Bagging** — ансамбль DecisionTreeClassifier.
- **ML5 — Stacking** — LogReg + SVC + DecisionTree, финальный LogReg.
- **ML6 — Neural Network** — [128→Dropout(0.3)→64→Dropout(0.2)→32→Softmax(3)].

### 1.2 Инструменты сериализации

Сериализация моделей выполнена с использованием:
- **`pickle`** — для моделей scikit-learn (Ridge, Bagging, Stacking, LogReg), а также для `StandardScaler`, `ColumnTransformer` [1].
- **Встроенные методы `save_model()` / `load_model()`** — для CatBoost (`cbm`) и XGBoost (`pkl`) [4, 5].
- **`model.save()` / `keras.models.load_model()`** — для TensorFlow/Keras моделей (`keras` формат) [2].

Такой подход гарантирует совместимость версий библиотек и быструю загрузку в продакшн-среде Streamlit.

## 2. РАЗРАБОТКА ДАШБОРДА НА STREAMLIT

### 2.1 Архитектура приложения

Приложение построено по мультипейдж-паттерну Streamlit:
- `app.py` — точка входа и навигация
- `pages/about.py` — страница разработчика
- `pages/data_info.py` — описание датасетов и EDA
- `pages/visualizations.py` — 4 типа графиков для каждой задачи
- `pages/prediction.py` — страница инференса со всеми моделями

### 2.2 Описание страниц дашборда

**Страница 1 «О разработчике»** содержит: ФИО, группу, тему РГР, аватар аватарабельного стиля, перечень используемых технологий и описание цели работы.

**Страница 2 «О наборе данных»** включает:
- Таблицу признаков с типами и описаниями.
- Первые 5 строк датафрейма (DataFrame) и строку с размерами.
- Краткое EDA и перечень шагов предобработки: удаление пропусков, One-Hot Encoding / StandardScaler, train/test split 80/20.

**Страница 3 «Визуализации»** содержит минимум 4 вида графиков для двух задач:
- *Регрессия:* `histplot` — распределение цены, `heatmap` — корреляция числовых признаков, `barplot` — средняя цена по маркам, `boxplot` — цена по типу топлива.
- *Классификация:* `pie chart` — распределение классов, `heatmap` — корреляция факторов риска, `violinplot` — BMI по классам диабета, `stacked bar` — процент диабета по уровню здоровья.

**Страница 4 «Предсказание»** обеспечивает:
- Выбор задачи и модели из выпадающего списка.
- Две формы ввода: **ручной ввод** через интерактивные виджеты (`selectbox`, `slider`, `number_input`) и **загрузка CSV** через `st.file_uploader()`.
- Валидацию входных данных на совпадение ожидаемых колонок.
- Кнопку инференса (`st.button`) с выводом результата в человекочитаемом формате (цена в USD с разделителями или диагноз с цветовой индикацией).
- Рекомендации пользователю на основе результата предсказания.

### 2.3 Фрагменты исходного кода

Конфигурация страниц дашборда:
```python
st.set_page_config(
    page_title="ML Inference Dashboard",
    page_icon="🤖",
    layout="wide",
    initial_sidebar_state="expanded",
)
```

Загрузка и кэширование моделей:
```python
@st.cache_resource
def load_model(path, model_name):
    if path.endswith('.keras'):
        return keras.models.load_model(path)
    elif path.endswith('.cbm'):
        model = CatBoostRegressor()  # или Classifier
        model.load_model(path)
        return model
    else:
        with open(path, 'rb') as f:
            return pickle.load(f)
```

Инференс регрессии:
```python
if model_name.endswith("CatBoost"):
    pred = model.predict(input_df)
elif model_name.endswith("TensorFlow)"):
    prep = load_preprocessor("models_regression/preprocessor.pkl")
    X_proc = prep.transform(input_df)
    pred = model.predict(X_proc).flatten()
else:
    pred = model.predict(input_df)
```

## 3. ДЕМОНСТРАЦИЯ ПРОГНОЗИРОВАНИЯ

### 3.1 Корректные данные

**Пример 1 (Регрессия):** Новый BMW X5 2020 г., 30 000 км, бензин, автомат — модель прогнозирует цену **~$47 000 USD**.

*Почему выбрано:* данные отражают премиальный сегмент с низким пробегом и современным годом выпуска, что является стандартным значимым случаем.

**Пример 2 (Классификация):** Пациент с BMI=22, нормальное давление, физическая активность = Да, хорошее общее здоровье (GenHlth=2) — модель указывает «Нет диабета» (класс 0).

*Почему выбрано:* типичный здоровый пациент, демонстрирующий работу модели на чистых данных без факторов риска.

*(Скриншоты предсказаний для корректных данных размещены в Приложении А).*

### 3.2 Данные с выбросами

**Пример 1 (Регрессия — выброс):** Toyota Corolla 2005 г., 300 000 км, ручная КПП — модель выдаёт **~$2 100 USD**, что ниже рыночной цены.

*Объяснение:* пробег сильно превышает средний диапазон обучающих данных (~0–200 000), поэтому модель занижает оценку, отражая затёртую линейную зависимость.

**Пример 2 (Классификация — выброс):** Пациент с BMI=55, высокое давление, инсульт, инфаркт, плохое здоровье (GenHlth=5), отсутствие активности.

*Объяснение:* все риск-факторы сконцентрированы в одной записи; модель классифицирует как «Диабет» (класс 2) с высокой уверенностью, хотя такая комбинация редка.
